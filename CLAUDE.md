## What this is

Grimoire is a desktop addon manager for The Elder Scrolls Online, built with Tauri 2 (Rust backend + React frontend). It fetches the full addon catalogue from the MMOUI JSON API (esoui.com) and handles install, update, remove, and backup. Targets Linux and Windows.

## Development commands

```bash
# Install deps (first time)
npm install

# Dev server (hot-reload frontend, no binary changes)
npm run tauri dev

# Production build
source "$HOME/.cargo/env"
npm run tauri build -- --bundles deb   # Linux .deb
npm run tauri build                    # all bundles

# Kill old process before rebuild if it's running
killall grimoire
```

Tauri embeds frontend assets at compile time — `npm run build` alone doesn't update the running binary; always use `npm run tauri build`.

## Architecture

### Rust backend (`src-tauri/src/`)

`lib.rs` registers all `#[tauri::command]` handlers and wires up plugins. Core logic lives in `src/core/`:

| File | Responsibility |
|---|---|
| `esoui.rs` | MMOUI API client. `static CLIENT: Lazy<reqwest::Client>`, `static API_URLS: OnceCell<ApiUrls>` (lazy URL init). `RemoteAddon` has `date: i64` (Unix ms). |
| `addon.rs` | `InstalledAddon` struct, manifest parser, `scan_addons_dir()`. Writes `.grimoire.json` sidecar `{"addon_id": u32, "install_date": i64}` on install. |
| `installer.rs` | Download → extract zip → write sidecar. `install_addon()` overwrites in place. `remove_addon()` does `fs::remove_dir_all`. |
| `backup.rs` | Zips `AddOns/` (and optionally `SavedVariables/`) using `walkdir` crate. Returns `Vec<BackupEntry>` with name/path/size_mb/date. |
| `config.rs` | JSON config at `~/.config/grimoire/config.json` (Linux) / `%APPDATA%\grimoire\config.json` (Windows). |
| `paths.rs` | Platform-aware AddOns dir detection; parses Steam's `libraryfolders.vdf` for Proton/Steam Deck. |
| `dependency.rs` | Unused BFS dep resolver (kept for reference). |

Progress streaming uses `tauri::ipc::Channel<String>` — the frontend creates a `Channel`, passes it as a command arg, and Rust calls `channel.send(msg)`.

### React frontend (`frontend/src/`)

| File | Responsibility |
|---|---|
| `App.jsx` | Root state: `allAddons` (Vec<RemoteAddon>), `installedMap` (name→InstalledAddon). Auto-detects addons dir on first launch. |
| `InstalledTab.jsx` | Installed addons table. Click toggles selection (checkbox-style, no modifier needed). Ctrl+A selects all. Right-click context menu for remove. Delete key removes selection. |
| `BrowseTab.jsx` | Browse/search remote catalogue. `buildRemoteMap()` maps both `a.name` and `a.dirs` entries. Install streams progress via Channel. |
| `BackupTab.jsx` | Create/restore/delete backups. |
| `Settings.jsx` | Config editor with folder pickers. |

`document.addEventListener("contextmenu", e => e.preventDefault())` in `main.jsx` suppresses the native WebKit context menu globally.

## Packaging

- **Flatpak** (`io.github.khedron83.Grimoire.yml`): uses `org.freedesktop.Platform//24.08` + rust-stable + node22 extensions. Offline build requires `cargo-sources.json` and `node-sources.json` (generated by `flatpak-cargo-generator.py` and `flatpak-node-generator`).
- **CI** (`.github/workflows/build.yml`): builds Linux deb + Windows installer on every tag push.
